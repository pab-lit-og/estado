# Estado del servicio

Página pública de estado de OptiCliniq, OposiVoz y EyeLab: **https://pab-lit-og.github.io/estado/**

GitHub Actions comprueba cada pocos minutos, desde fuera de nuestros servidores, que cada servicio responde.
Si uno se cae, se abre una incidencia en este repositorio y aparece en la página hasta que se resuelve.
Hecho con [Upptime](https://upptime.js.org).

## Mantenimiento programado

Para anunciar una parada prevista, abre una incidencia con la plantilla «Mantenimiento programado» y pon el
inicio, el fin y los servicios afectados. Sale en la página y, mientras dure, no se abre ninguna incidencia.
